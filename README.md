# Systems Foundry

An engineering portfolio of self-contained Java21, Rust, C++ and browser projects, with an integrated fictional logistics demo.

Development is in progress. Runnable examples, test results, screenshots and measured benchmarks will be added after validation. This project has no affiliation with any institution.

Planned projects:
- Chronicle: Rust durable, hash-chained audit log and CLI.
- Dispatch: exact C++ minimum-cost assignment solver and property tests.
- Control API: Java21 HTTP service with persistence, concurrency and event streaming.
- Control Room: interactive HTML/CSS/JavaScript dashboard.

The kernel work is maintained separately as kernel-workpulse.
